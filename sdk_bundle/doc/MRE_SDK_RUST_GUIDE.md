# Exhaustive MRE SDK Rust Guide

This document provides a comprehensive, LLM-friendly guide on how to build MRE applications in Rust, covering **every single feature and API** of the SDK.

## 1. SDK Setup and Usage in Rust

To use the MRE SDK from Rust, your code must interface with the C FFI bindings generated by `bindgen`.

### Building the Application
1. **Cargo Configuration**: Ensure `Cargo.toml` specifies `crate-type = ["staticlib"]`.
2. **Target**: Build for ARM using `cargo build --target armv5te-unknown-linux-gnueabi --release`.
3. **Linker**: Use the existing MRE Makefile to link the resulting `.a` library with the SDK's C shims (`c_fix.c`, `gccmain.c`) and `.vxp` packager.

### Writing the Entry Point
The MRE system expects a `vm_main` C-compatible function. Define it as follows:
```rust
#[no_mangle]
pub extern "C" fn vm_main() {
    unsafe {
        vm_reg_sysevt_callback(Some(handle_sysevt));
        // register other callbacks...
    }
}
```
